# Contributing

Read [AGENTS.md](AGENTS.md) first. Its layout, commands, code rules and contract rules apply to people too.

- Open an issue before a big change.
- Branch from `staging` and open the PR against `staging`. `main` only moves through promotion PRs that maintainers merge.
- Use Conventional Commits (`fix: …`, `feat: …`). Every behaviour change comes with a test that fails before it and passes after.
- Run the commands in AGENTS.md for every package you touch and say in the PR what you ran.
- Security issues go to [SECURITY.md](SECURITY.md), never to a public issue.
